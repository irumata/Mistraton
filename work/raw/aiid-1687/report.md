# Incident 1687: Anthropic-Designated GTG-87001 Weapons Cell in Northern Yemen Reportedly Used Claude Code to Develop Missile Guidance Software

- Incident date: 2026-09-10 (first public disclosure; activity spanned 12/2025-08/2026)
- Source: AI Incident Database (input to the MIT AI Incident Tracker), https://incidentdatabase.ai/cite/1687

Anthropic reported that a northern Yemen-based weapons cell, designated GTG-87001, used Claude Code across three weapons programs to develop guidance, navigation, and control software. The actors reportedly test-fired a guided rocket that appeared to fail, then returned to Claude for failure analysis. Anthropic said it banned associated accounts, shared threat intelligence with partners, and strengthened safeguards. On 09/11/2026 FT/AP connected the location to Houthi-controlled territory, though Anthropic did not identify the actors as Houthis.

Alleged implicated AI systems: Claude Code, Claude, LLMs, chatbots, AI agent systems. Deployed by GTG-87001 threat actors. Harmed: national security and intelligence stakeholders.
