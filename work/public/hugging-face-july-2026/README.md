# Hugging Face July 2026 public incident timeline

Hugging Face published these five UTC daily totals of recovered actions in the Volume per day chart of its [technical timeline](https://huggingface.co/blog/agent-intrusion-technical-timeline). The totals sum to 17,613 and cover the reconstructed activity from 9 July at 02:28 UTC through 13 July at 14:14 UTC. The first and last days are partial. The chart animates its counter by interpolating between the five daily totals.

This export contains daily forensic counts. It has no normal-activity baseline, raw detector alerts, production latency, or error-rate measurements. The timestamps mark UTC day buckets. Use the counts to describe activity during the incident. An early-warning evaluation requires separately collected baseline and incident-period monitoring signals.
